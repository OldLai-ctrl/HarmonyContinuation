# 独立进行库与安装器回传

产品版本：`0.8.0-dev.1-installer.1`。分支：`v0.8/dev`。

## 已完成

- 提取 `LibraryStore`，插件、后台推荐及 Demo 使用统一库路径和选择规则。
- 全部个人进行继续留在原来的 `LocalAppData/HarmonyContinuation/user.db`。
- 内置库独立保存于 ProgramData，按内容版本归档；切换当前库前验证数据，保存旧版本，防止旧安装包意外降级。
- 数据库格式版本仍为 1，内置库内容版本仍为 2，当前库仍是原来的 161 条，音乐推荐算法未调整。
- 从生产解析模块移除测试用内嵌进行，修复数据库打开失败的资源释放，并增加输入规模和数据身份检查。
- 提供完整 Windows 安装程序及单独的进行库安装包；安装、更新、修复、卸载均保留个人进行与已安装的库历史。
- 插件占用时拒绝替换，包内携带必要运行库；提供简中与英文安装界面、系统卸载入口及开始菜单入口。
- 保留随插件附带库，独立库不可用时安全回退并显示原因。

## 当前实际验证

- 库管理定向检查：17 项通过。
- 原有个人库/状态/后台推荐相关检查：68 项通过。
- 实际隔离安装器：18 项通过，包括首次安装、占用拒绝、单独更新库、重装不降级、卸载及数据保留。
- Release 插件与 Demo 均构建成功；VST3 Validator 47/47。
- 没有重复和声基线、缩放全矩阵或全量 CTest。没有在 Cubase 中安装/人工复测本轮新包。

## 使用边界

- “更新”指运行新版离线安装包；未实现联网版本检查或自动下载。
- 完整包要求管理员权限，使用系统标准 VST3 目录。
- 安装器是尚未签名的开发包。
- 当前插件实例缓存库，更新后需重新打开实例。
- 卸载有意保留所有进行数据；手动清理前应备份。
- 没有进入 MIDI Import 开发，没有合并 main、打发布标签或推送远端。

构建、目录和后续单独发布进行库的操作见 `docs/INSTALLER_AND_LIBRARY.md`。安装产物与 SHA-256 位于 `build-installer/output/`。
