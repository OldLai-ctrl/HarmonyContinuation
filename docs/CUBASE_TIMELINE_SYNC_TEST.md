# Cubase 播放同步手测

2026-09-24 状态：用户报告非零位置、前后跳转、循环播放及工程关闭重开均无问题。以下步骤保留为复测规程；导入和弦在完全重启 Cubase 后是否无需重新拖入即可恢复，仍需与当前源码的保存行为核对。

目的：确认插件在 Cubase 播放、定位和循环期间自动更新工程 QN，并高亮当前导入和弦。本测试不重新验证 QN 坐标换算：用户已确认拖入的和弦 QN 是 Cubase 工程绝对位置。

## 准备

1. 先构建最新插件。关闭 Cubase 后，以管理员身份打开 PowerShell，在项目目录运行 `powershell -ExecutionPolicy Bypass -File tools\install-debug.ps1`。脚本会先检查 Cubase 未运行、备份旧二进制，再安装并核对 SHA-256。
2. 再运行 `powershell -ExecutionPolicy Bypass -File tools\verify-installed-build.ps1`。只有显示 `MATCH` 才开始测试。若插件安装在其他 VST3 扫描目录，请用 `-InstalledBinary` 指定该目录中的插件二进制。
3. 在 Cubase Pro 15.0.30 Build 287（x64）中新建临时工程，设为 120 BPM、4/4。创建和弦轨，并在工程位置 0、4、6、7 QN 放置 C7、Amin7、A7、Dmin7 四个事件。
4. 在一个正在播放音频的音频轨插入 HarmonyContinuation，打开编辑器，将四个和弦事件一起拖入插件。

## 播放与定位

确认插件显示四个和弦块及 4、2、1、开放时长。播放经过 0、4、6、7 QN，观察黄色播放头和当前和弦边框。无需点击“刷新宿主上下文”。

| Cubase 工程位置 | 预期高亮 |
|---:|---|
| 0 至 4 QN 之前 | C7 |
| 4 至 6 QN 之前 | Amin7 |
| 6 至 7 QN 之前 | A7 |
| 7 QN 及之后 | Dmin7 |

播放中再直接定位：

1. 从约 1 QN 跳到 6.5 QN，插件应切换到 A7。
2. 从约 6.5 QN 跳回 3.5 QN，插件应切换到 C7。
3. 设置跨过多个和弦的循环范围，确认循环回绕时高亮也随工程位置来回更新。
4. 停止播放，确认播放头停在当前位置且界面不闪烁。

播放期间的界面同步目标约为 20 Hz；定位和循环回绕应在下一次轮询后更新，通常不超过约 0.1 秒。Cubase 的 `ProcessContext::Chord` 仍可能显示无效，这不影响本测试或和弦定位。

## 回报结果

请回传以下信息：

- 是否能打开插件并成功导入四个和弦；
- 播放经过各和弦时，高亮是否对应表格；
- 前跳、后跳和循环回绕是否正确；
- 是否仍需手动点击刷新；
- 插件窗口截图，以及 hash 工具显示的 `MATCH` 结果。

如果某一项不符，请注明 Cubase 位置、实际高亮和插件诊断面板中的工程 QN/有效状态。
