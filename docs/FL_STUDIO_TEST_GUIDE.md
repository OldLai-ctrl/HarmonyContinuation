# FL Studio 0.9.0-dev.1 简短测试清单

本版是兼容性测试候选，真实 FL 验收尚未完成。使用一个测试工程即可，不需要重新评估全部音乐算法。

## 安装与示例

关闭宿主，运行 ZIP 内的 `HarmonyContinuation-0.9.0-dev.1-Setup.exe`。按 [使用教程](../README.md) 扫描并从 Mixer 的效果器插槽加载。

完整安装包已经包含曲库。独立 Library 2 安装包仅用于单独安装/更新曲库，不是必须再运行的第二步。

在「更多 → 关于」确认 **0.9.0-dev.1 / ac40822**；曲库实际版本应为 **2**、内置条目应为 **161**。

ZIP 中的 `examples/` 提供以下 MIDI（QN = 四分音符拍）：

| 文件 | 预期内容 |
|---|---|
| pop_block.mid | C → Am → F → G；起点 0、1、2.5、4.5 QN；时值 1、1.5、2、2.5 QN，总长 7 QN。 |
| inversion_block.mid | C → G/B → Am；总长 4.5 QN。留意 G 的根音与 B 低音分开。 |
| sevenths_block.mid | Cmaj7 → Am7 → Dm7 → G7；节奏与 pop 文件相同。 |

## 只做这一轮

每项记为 **通过 / 问题 / 未测**，不要把未测写成通过。

| 项目 | 怎么试 |
|---|---|
| 加载 | 扫描、打开，核对版本与曲库，切换简中 / English。 |
| MIDI 导入 | 「更多 → 导入 MIDI → 完整片段」，依次试三个示例，核对和弦和节奏。 |
| OPEN | 再以「作为未完成进行」导入 pop；最后和弦应标 OPEN，且能继续发展。 |
| 两种模式 | 在继续发展、升级进行中各选择一个方案；试听、切换、停止，查看 Why 和保存快照。 |
| 更多与滚动 | 查看更多候选，从主界面滚动后的候选试听、保存和拖出。 |
| MIDI 保存与拖出 | 继续发展 / 升级进行的可见候选和更多候选各试一次。分别记录 Playlist、Piano Roll 是否接收，以及是否出现额外标记。 |
| 内容对照 | 同一候选的保存 MIDI 与拖出 MIDI，导入后音符、节奏及长度应一致。 |
| Explorer 拖入 | 从 Windows 文件管理器拖 pop 到当前进行区；记录 Wrapper 的 Accept dropped files 开关状态。 |
| 缩放与窗口 | 试 100% / 125% / 150%，确认文字、点击位置和弹层正常；关闭重开窗口、试 Detached。 |
| 工程恢复 | 导入片段，设置模式、风格、倾向、一个旋律约束及缩放；保存工程、退出 FL、重新打开，核对恢复情况。 |
| 多实例 | 可选：开两个实例；互相切换试听，关闭没有在试听的实例，当前声音不应被它停止。 |
| 诊断 | 「更多 → 导出宿主诊断」，把文件随反馈提供。 |

试听使用 Windows 默认播放设备，不经过 FL 混音器。特定 FL 目标能否接收拖出 MIDI，正是本轮测试内容；失败时用保存 MIDI 继续其他项目，并记录失败。

FL 内部 Piano Roll / Playlist 片段直接拖入插件不属于本轮成功条件；使用标准 MIDI 文件。部分推荐组为空或收束只有一个和弦也不自动算故障。
