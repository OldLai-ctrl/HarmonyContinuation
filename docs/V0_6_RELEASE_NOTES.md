# HarmonyContinuation 0.6.0

HarmonyContinuation 可读取 Cubase 和弦轨中的已有段落，帮助你继续发展和声，或升级已有进行。默认界面为简体中文，可切换 English。

## 本版功能

- **继续发展**：从收束、发展、循环、色彩四个方向查看候选与原因。
- **升级进行**：用润色、丰富、进阶三个方向改造已有段落。
- **进行库**：提供 161 条带中英文名称的内置进行，支持搜索、标签筛选、收藏、自定义进行及直接选择页码。
- **方案操作**：试听、对比、保存 MIDI 文件与快照。
- **工程使用**：保存并恢复插件状态；窗口可调整大小。

## 当前边界

- 试听经 Windows 默认播放设备输出，尚未接入 Cubase 的插件音频总线。
- MIDI 以 `.mid` 文件保存，尚不能直接拖回 Cubase。
- 普通 MIDI Part 的自动和弦识别尚未实现；当前输入以 Cubase 和弦轨为主。
- 部分推荐方向可能没有候选，系统不会为填满界面而生成低质量结果。
- 单个和弦也可能是完整、合适的续写结果，例如直接完成收束。

RC2 已由用户在 Cubase 中复测通过。正式包由 `v0.6.0` 发布提交重新构建。
