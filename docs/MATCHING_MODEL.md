# Phase 2 容错进行匹配模型

## 范围与输入

这一阶段只判断导入的和弦进行与哪条完整模板相似，并返回模板中的对应位置。`continuationStartIndex` 是一个位置标记；不会生成或推荐后续和弦。测试模板位于 `tests/fixtures/progressions/templates.json`，共 50 条，编入插件仅供 MATCH 开发视图使用，不是产品曲库。

模板的 `MatchEvent` 只保存调内级数、变化音、性质、功能、角色、结构权重与时值，没有绝对根音。次属符号的显示名与实际根音级数分开：例如 C 大调 `V7/ii` 显示为 `V7/ii`，用于对齐的根音级数是 VI、目标是 ii。`MatchQuery` 保存同一输入在多个调性下的解释。默认取置信权重达到 0.005 的前三种调性；强制调性时只建立该解释。调性权重只占最终分数 0.025。

## 对齐边界

对每个调性、每条模板分别执行两次半全局对齐。查询中的所有和弦必须被消费。

- 模板开头可跳过，每颗代价 0.05；因此可以从模板中间开始匹配。
- 查询开头不能免费跳过，须按实际插入代价计算。
- 查询内部的插入和模板内部的删除都按和弦重要性计算。
- 查询结尾若是结构性插入，代价再乘 1.85，避免把错误的最后一颗和弦轻易丢掉。
- 选定终点后的模板后缀不扣分。`templateMatchEnd` 是最后对齐到的模板位置；`continuationStartIndex = end + 1`，可能等于模板长度。

每一步保存 `Match`、`Substitute`、`QueryInsertion` 或 `TemplateDeletion`、两边的索引、代价和结构化原因标记。前缀跳过与后缀尚未发生的部分没有列入 trace。

## 和声代价

替换代价考虑级数是否相同、级数变化音、三和弦或七和弦性质、功能、角色、次属目标及借用和弦关系。同音的升一级与降二级记谱只产生 0.06 的差异，并在 trace 中标记 `EnharmonicDegree`。相同级数优于同功能的不同级数；同级数的借用小和弦优于无关级数。一个错误和弦的基础替换代价上限为 1.30，防止算法把它拆成一次删除加一次插入。

插入或删除代价以 `0.35 + 0.44 × structuralWeight` 为基数，再按功能和角色调整。经过和弦乘 0.36、趋近和弦乘 0.55、次属乘 0.72、主功能延长乘 0.85、结构性下属功能乘 1.30、属功能乘 1.75、终止式角色乘 1.55；终止主和弦再乘 1.35。因此一拍的 V7 仍比经过和弦重要。所有数字集中在 `MatchWeights`，可在人工听感评估后统一调整。

若查询停在与模板相同的属和弦上，不因模板后面可能接 I 而对查询缺少“终止式”标记扣分。这使未写完的 `I–vi–ii–V` 可以正确对应完整的 `I–vi–ii–V–I`。

## 双层与节奏

FULL 保存所有和弦，SKELETON 取结构事件。两层分别对齐，最终按 0.68 和 0.32 合成；次属、经过、性质和借用细节在 FULL 中保留。SKELETON 的时值覆盖到下一颗结构和弦，因此插入短经过和弦通常不会破坏骨架节奏。

节奏不比较原始拍数是否相等。对齐后从已匹配且时值已知的和弦对估计统一缩放比例，取比例中位数，再按相对偏差计入代价。查询末尾的 OPEN 和弦不参加比例估计，也不产生节奏不匹配代价，仍参加和声匹配。对齐路径搜索时先用各序列中位时值做轻量节奏参考，最终用已匹配的时值对校正节奏分数。重复和弦且节奏极端时，路径仍可能需要人工复核。

## 分数、索引与结果

每层相似度约为 `exp(-校正后代价 / (查询长度 × 0.75))`，约束到 0–1。最终分数为两层加权结果的 97.5% 加调性权重的 2.5%。它是相似度，不是发生概率。`MatchResult` 另存原始 FULL 代价、调性解释、调性权重、起止位置、后续位置及长度、完整 trace、模板符号，以及结构、完整、功能、角色、节奏、调性分项。

`ProgressionFingerprint` 包含调式、骨架级数对应的相对音高及相邻对、骨架长度、结尾功能、终止式、相对节奏形状、结构事件数和角色摘要。相对音高使升一级／降二级进入同一筛选桶。`CandidateIndex` 在内存中生成指纹；模板超过 800 条时挑选最多 800 条候选送入对齐。筛选以召回为优先，仍不能从理论上保证任意 10,000 条中的正确模板必然入围；已有埋在末尾的精确模板测试。

## 插件与开发工具

插件只在成功导入新进行时计算 MATCH；打开编辑器和播放头移动只读取缓存结果。超过 64 个和弦时，MATCH 开发视图显示跳过信息，原有和声分析与时间轴照常运行。界面上方 `[ MATCH ]` 可切换到 Top 5，点击候选显示对应关系。命令行：

```text
build-vst3\progression_match_cli.exe query.json tests\fixtures\progressions\templates.json [--key C:major]
```

当前没有风格筛选、正式曲库、续写、音频试听、导出、持久化或网络功能。`styleHint` 仅保留接口。Cubase 实机烟测尚待用户回到电脑后完成。
