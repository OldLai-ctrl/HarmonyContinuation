## 最短操作

下列步骤待安装缺陷修复并重新过门禁后执行：在有备份的测试机器关闭宿主后运行 Setup，选择 VST3 与 Factory 两组件。重新扫描插件，在「更多 → 关于」核对版本和 BuildCommit，进入第六主入口「和弦祈愿」。默认自由随机，直接点「一抽」或「十抽」；抽取不会自动播放。开发包沿用正常安装路径和管理入口，会更新所选的已安装组件；本轮代理仅执行隔离安装，未安装到生产路径。

## 数据与质量边界

Factory保持V5 / Schema2 / 658，Session5 / Snapshot3 / 用户库格式不变。版本化独立标注沿用[v2目录](../data/mode-annotations/v2/README.md)：727个归属，687个结构编辑审校通过、40个未确认；633条至少有一个已审校解释。未确认解释不进入调式筛选。原三条进行、四项归属保留。常用程度是编辑评级，不是统计频率或抽样概率。

Locrian、固定上行旋律小调与古典旋律小调缺少已审校数据；25条只有未确认解释。严格筛选可能排除含借用/副属变化的已归属进行，这属于完整音集条件。多标签不增加票数，相近家族仅作柔性多样性处理，未将疑似相近组直接并为重复。当前结构审核不能替代用户听评或外部专家复核；不为填满卡池修改Factory或权重。

G4代表性结构复核未发现抽样缺陷。已知标注文案精度问题：`COMMON_MINOR_016` 的通用依据提到小下属/降VI体系，实际该条的降六级来自bII和弦；和声小调终止解释及严格筛选结论仍成立，冻结数据未更改。后续编辑校订宜明确写出bII。
