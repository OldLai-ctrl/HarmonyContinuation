# B6 Factory 检索覆盖与统计适配

**结论 B。检索修复收益有限，保留默认关闭的端点实验和离线统计适配。** 原 100 个输入恢复 1 个近似后句。67 个独立输入新增 2 个合格的 Factory 后句，目标近似可达数未增加。统计回退改善了 Billboard 和 MPB 的低频概率估计，Factory 排序的独立支持仍只有 3 个可达样本。

## 62 个未达案例

原版 Exact 默认扫描全库，Contextual 已包含合法内部落点和 4/3/2 和弦上下文。完整列表无按组截断。用原 Worker 跟踪目录近似尾段及可产生对应实际音高的调性解释：

| 退出阶段 | 输入数 | 观察 |
| --- | ---: | --- |
| 已进入匹配或候选构造，未过原资格 | 30 | Exact 有 379 条低于最低匹配度、11 条低于最低资格分。Contextual 有 3 条 Resolve 仅走 Exact |
| 原搜索没有形成对应窗口或解释 | 32 | 可见其他落点及调性，以及 Contextual 的来源不匹配、中心与拍号限制 |
| 已过资格但被去重、容量或分页隐藏 | 0 | 未观察到已通过且同一尾段、同一调性投影的近似后句 |

第二组中确认 1 个可修复的实现遗漏。原最佳路径消耗了非循环来源 `V3_HOME_055`，较早的落点未获得资格评估。原匹配度 0.824 的路径止于第 7 个事件，无后句；第 3 个事件后的尾段按原规则取得匹配度 0.777、资格分 61.77，距离 1，进入实际列表（Factory 第 22、实际混排第 24）。结构资格仍未知。其余 31 个原搜索未形成对应窗口或解释的输入，没有证据支持恢复。62 个案例按输入计数；同一输入可有多个路线和退出原因。

独立的定点反事实按原生来源接缝筛选出 45 个输入、795 个来源尾段、4,094 条 Exact 解释。强制候选落点后，4,036 条低于匹配门槛、47 条低于资格分、10 条末和弦未对齐，只有上述 1 条通过。原路径实际退出为 `no_continuation` 的 61 条路线涉及 9 个输入，其中 60 条强制落点仍被原门槛挡下。原生接缝探针与 Worker 跟踪采用不同见证筛法，计数各自独立。未找到近似候选的其余 29 个开发输入在乐库内容层就没有符合 B5 距离定义的完整尾段。音集、低音、时值、来源结构及调性限制继续适用。四个输入和弦均有时值，这批证据没有单独覆盖 OPEN。

## 最小检索改动

只在 B6 试验请求开启、Unified、非循环 Factory 来源的最佳全输入对齐到达来源末端且末和弦实际参与时，复用同一 DP 表选一个最佳较早落点。候选经过原 Exact 最低匹配度、末端对齐、实际定义音和低音冲突、演奏实现、旋律硬约束与最低资格分。保留原结构匹配口径，候选仍使用既有来源尾段和节奏缩放，不将替代落点标为已审校结构。Contextual 行为只增加选择性诊断。实验关闭时，100 个原输入的候选顺序、分数和演奏字段逐项等于冻结 B5 回放。

## 统计可靠性

沿用 B5 作品组和计数。比较固定 1/8 边际混合与按最长上下文的作品支持量缩放混合；仅用 Billboard 验证集选择。固定混合在验证集低频 NLL 6.984→5.650，困难 MRR 0.467→0.468，保留原 lift。下一和弦概率仍在同一符号表归一。未给罕见或非调内类别加分。

| 独立指标 | Billboard B5 → B6 | MPB B5 → B6 |
| --- | ---: | ---: |
| 整体 NLL ↓ | 2.370 → 2.268 | 3.533 → 3.310 |
| 低频转移 NLL ↓ | 7.727 → 6.112 | 7.943 → 6.839 |
| 困难 MRR ↑ | 0.465 → 0.471 | 0.355 → 0.362 |
| 困难 Recall@3 ↑ | 53.7% → 56.1% | 39.0% → 40.5% |
| 普通 MRR ↑ | 0.633 → 0.644 | 0.509 → 0.521 |

MPB 非调内根音 NLL 6.371→5.452（435 个事件，259 组），低频和非调内 NLL 仍高于 B5 固定三阶基线的 6.662 和 5.098。MPB 小调困难 MRR 0.357→0.367，复杂或特殊和声 0.344→0.352。Billboard 困难 MRR 的配对区间仍含 0（−0.0005 至 +0.0132），MPB 为 +0.0027 至 +0.0104。没有重训，也没有改动 CC0 模型文件。

## 联合评估

独立确认按作品组冻结，7 首 Billboard 来自原 100 个输入以外的测试组，60 首 MPB 从外测组按固定哈希取样。MPB 的四和弦输入使用等间隔 4 QN 测试网格、拍号未知，反映和弦序列适配。7 首有符号时值的 Billboard 输入中，3 首有目录近似、1 首有源接缝近似，原版与回退均未返回近似。MPB 60 首中有 34 首目录近似、27 首源接缝近似，回放可达的 3 首均来自这一组。

| 模式 | 开发组 100 首：可达 / Top3 / Top10 / MRR | 确认组 67 首：可达 / Top3 / Top10 / MRR |
| --- | ---: | ---: |
| 原检索、原序 | 9 / 2 / 5 / 0.0162 | 3 / 0 / 1 / 0.0043 |
| B6 检索、原序 | 10 / 2 / 5 / 0.0166 | 3 / 0 / 1 / 0.0043 |
| B6 检索、纯 B5 统计 | 10 / 5 / 9 / 0.0527 | 3 / 2 / 2 / 0.0224 |
| B6 检索、纯适配统计 | 10 / 5 / 9 / 0.0521 | 3 / 2 / 2 / 0.0225 |
| B6 检索、保守适配混合 | 10 / 3 / 5 / 0.0246 | 3 / 1 / 1 / 0.0088 |

TopK 是命中输入数，除以组样本数即 Recall@K；MRR 以全组为分母，未达计 0。检索回退保持 3 个开发组、1 个确认组完全相同的后句可达。开发组独立候选 21,021→21,068，确认组 12,923→12,925，原有音乐身份和主来源均未丢失或改变。Exact 对齐路径分别增加 100,223 和 50,954，实际进入列表的新增候选为 47 和 2。Contextual 通过数一致。混合只在原前十名、至少 10 个作品支持的位置以原序与统计名次求和，B5 原统计与适配统计在该混合下得到相同命中指标。确认组纯统计的 MRR 提升基于 3 个已存在的候选集合。

## 核验与接续

Windows x64 Release 顺序回放 Worker 中位/P95，开发组 287/411→303/403 ms，确认组 275/362→281/370 ms。两组 ON/OFF 共核对 167 个输入；生成身份一致，G13 按原插入规则，分页每页最多 10 条，公共候选的音集、低音、时值、来源与原回放一致。针对恢复的尾段，在首和弦放入冲突的 D 音，确认原硬旋律门以 `melody_constraint` 拒绝该候选。未进行插件或 DAW 验收。Factory V8 数据库、HCA 与正式版本保持；统计评分在离线工具，未进入 Worker 或产品包。

主代理负责根因决策、实现和联合复核，子代理负责定点反事实与统计可靠性。接续见 [RUNBOOK](../RUNBOOK.md#b6-factory-检索与统计适配) 与 [MAP](../MAP.md#b6-外部证据身份)。下一步优先审查经过接缝与资格后仍缺少有效尾段的素材类型，按真实来源补足对应语境。现有证据支持保留单落点实验及概率适配作为对照，产品接入仍需更多有真实时值的独立输入及听评。
