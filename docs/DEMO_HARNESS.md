# HarmonyContinuationDemo

Build the full `build-vst3` configuration, then run `build-vst3/HarmonyContinuationDemo.exe --case D`. The Windows window has a Case A–H dropdown, Play/Pause, a Project QN slider, and the same `MainView` used by the plugin. The case loads immediately and runs the actual harmony analyzer, matcher, factory/user database loader, and continuation worker. Only the incoming chord phrase and host transport are simulated. Tempo defaults to 120 BPM and the slider uses quarter-note positions. The top Play/Pause simulates transport without audio. A recommendation card's ▶ plays its full existing-plus-recommended phrase through an offline WAV and Windows playback; ■ stops it, and another ▶ replaces it. Audio playback is in the standalone demo only.

Scenarios live in `tests/fixtures/demo/case_a.json` through `case_h.json`. Each object contains `name`, `tempo`, `meter`, and a `chords` array; optional `forcedKey`, `style`, and `intent` fields can be added. `chords` use the established flat progression JSON format with `name`, `start`, and optional `duration`. Case F uses a forced A minor interpretation. To add a case, provide a valid file and extend the dropdown's case list; the parser and complete pipeline are also exercised by `ProductizationTests`.

The demo reads `factory.db` beside its executable. Its user database is `%LOCALAPPDATA%\HarmonyContinuation\user.db`, like the plugin. Save, edit, and delete operations therefore affect that real user library. The test executable uses a separate temporary database. The GUI timer is 250 ms while paused and 50 ms during simulated playback. Automated screenshot capture/pixel comparison is deferred; the demo supplies a repeatable human visual QA surface.

Phase 4B adds a `MIDI` and `SNAP` button to each recommendation card. `MIDI` saves the complete current-plus-recommended phrase as a Voice Led MIDI file. `SNAP` saves that specific recommendation as `.hcrec.json`. The top `Current MIDI` button saves only the incoming phrase; `Open Snapshot` restores a frozen recommendation for audition or export. The library inspector offers `Export MIDI` for both factory and user entries. Windows Save/Open dialogs are used only by this standalone executable. See [MIDI_EXPORT.md](MIDI_EXPORT.md) and [RECOMMENDATION_SNAPSHOT.md](RECOMMENDATION_SNAPSHOT.md).

For automated UI smoke checks, `HC_DEMO_AUTOSAVE_DIR` makes Save actions write under a specified directory without opening a dialog, and `HC_DEMO_SNAPSHOT_FILE` supplies the file used by Open Snapshot. These environment variables are Demo-only test hooks.
