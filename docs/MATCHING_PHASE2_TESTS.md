## 当前排序边界

- A 的 `M05` 完整终止模板与 `M22` 在输入前缀上同分。输入尚未提供能区分两个未来走向的信息；同分时按模板 ID 排序，不能把某个后续视作已被证实。
- G 只有一颗明显错误和弦时，`I–vi–IV–V` 与 `I–vi–ii–V` 并列。当前模型能找回目标模板，但无法确定错误和弦原本是 IV 还是 ii。这一组应在未来人工评估排序时重点检查。
- 100/1,000/10,000 条性能实验使用合成变体和当前机器的 Debug 构建，只说明当前实现的交互量级；不代表正式曲库的召回率或 Cubase 实机体验。
