# B5 真实音乐统计与 Factory V8 续接评估

**保留离线模型，暂缓产品接入。** 变阶模型提高了 Billboard 完整后句及 MPB 事件窗的困难候选排序。MPB 非调内根音与低频转移的概率估计变差，Factory 回放也只有 9 个输入出现可重排的近似后句，现有证据不足以支持增加产品排序开关。B1—B4 的历史结论沿用 [D18](../DECISIONS.md#d18-b5-用独立作品评估完整后句)。

## 数据与评价设计

| 划分 | 代表作品记录 / 作品组 | 可解析事件 L1/L2 | 有 QN 和相位 L3 | 有效事件窗 / 源标注行 |

| Billboard 训练 | 519 / 510 | 73,735 | 73,735 | 52,501 个 L2 变化事件用于学习 |
| Billboard 验证 | 111 / 109 | 17,124 | 17,121 | 873 / 388 |
| Billboard 测试 | 110 / 110 | 15,337 | 15,337 | 842 / 365 |
| MPB 外测 | 499 / 499 | 16,994 | 0 | 3,895 / 0 |

Billboard 740 个去重录音注释对应 729 个保守作品组。跨两语料共合并 11 个同标题关系和 1 个移调不变的长序列关系，排除 MPB 的 1 个跨库标题冲突。按固定种子 `b5-v1-20261113` 对 Billboard 作品组做 70/15/15 划分，检查所有正例与替代候选的作品组归属。异名、翻译题名和改编的身份仍可能遗漏，未取得全库可比的音频指纹。原始版本、许可和字段范围见 [语料清单](B5_CORPORA.md)。

L1 用根音和基础性质，L2 保留扩展、变化、显式低音和可解析的标注音集，L3 加符号 QN 时值与小节内位置。Billboard 的 L1/L2 有效事件中 9,533 个有显式低音，未知低音留空。MPB 保留小节分数位置，时值、拍号和节拍相位未知。原符号与来源记录保留在归一化数据。未知和弦与标注断点截断连续序列，连续相同 L2 和弦合并，训练时同一作品组对每个上下文/结果至多投一票。Billboard 的完整后句任务使用含 3–12 个变化事件的完整 SALAMI 注释行，每个正例输入前四个变化事件。另有两来源均可用的 3–6 事件窗口。SALAMI 行是注释单位，音乐分句的粒度仍有差异。

每项任务各有九个普通替代和九个困难替代，取自同一划分内其他作品组。替代后句按前一和弦移调对齐，保留后句内部关系。困难候选依次匹配首和弦的根音间隔和性质、长度、符号时值组、性质序列。测试和外测困难替代中首连接相同分别为 9,338/10,863 和 34,682/35,055，长度相同为 7,834/10,863 和 32,597/35,055。目标后续的调中心不进入评分，候选统一继承输入最后一个可靠调中心。对查询先按作品组平均，再跨作品组平均，同分取并列名次的期望。

## 统计模型与冻结选型

模型输出 120 个 L1 符号的条件概率。比较绝对/相邻根音边际频率、固定一至三阶，以及最高四阶的变阶插值。变阶比较绝对根音、以最新和弦根音为锚、相邻根音间隔、已标调中心。L2/L3 作为更丰富的输入上下文，输出仍按同一 L1 字母表比较。每级从下层回退，至少两作品组支持才使用该上下文。底层以 0.5 伪计数平滑，插值先验质量为 `8 × 转移计数 / 支持作品组数`。查询可读出有效阶数、作品组支持、概率和回退情况。

全后句比较总对数似然、每事件平均对数似然和每事件上下文增益。增益从给定输入的得分扣除候选在无输入时的得分，首和弦使用同一转移符号的边际概率。验证集以困难候选 MRR、完整源行 MRR、下一和弦 NLL 的次序选定 `variable_anchor + lift`，验证 MRR 0.467。基线选定 `fixed_3 + lift`，验证 MRR 0.413。绝对一元频率、固定阶及其他表示结果保留在同一份证据；下一和弦、复杂度、时值和跨来源各项均使用同一冻结数据。L2/L3 在验证困难集未超过选定 L1 模型。

## 实验 A 独立歌曲

| 指标 | Billboard 固定三阶 → 变阶 | MPB 固定三阶 → 变阶 |
| --- | ---: | ---: |
| 下一和弦 NLL ↓ | 2.489 → **2.370** | 3.532 → 3.533 |
| 下一和弦 Top-1 / Top-3 / Top-5 | 37.1 / 61.2 / 69.6% → **42.0 / 66.9 / 74.4%** | 19.2 / 32.2 / 37.8% → **25.8 / 44.1 / 52.8%** |
| 普通候选 MRR | 0.548 → **0.633** | 0.444 → **0.509** |
| 困难候选 MRR | 0.409 → **0.465** | 0.343 → **0.355** |
| 困难候选 Recall@3 | 48.1% → **53.7%** | 36.9% → **39.0%** |
| 完整源注释行困难 MRR | 0.417 → **0.472** | 无源行标注 |

困难 MRR 作品组配对自助法 95% 区间为 Billboard +0.031 至 +0.082（107 组），MPB +0.004 至 +0.021（495 组）。Billboard 测试中按序列总似然/平均似然/增益打分，变阶困难 MRR 分别为 0.388/0.397/0.465。MPB 分别为 0.317/0.317/0.355。仅在 L1 真变化事件上，困难 MRR 仍由 0.408 升至 0.464、0.342 升至 0.357。固定三阶只能退到边际频率的查询占 Billboard 11.9%、MPB 39.5%，变阶在两来源均找到至少一阶支持。MPB 仍有 2,035 个查询的最高支持低于 10 个作品组。

MPB 首续接事件标注大调的 2,948 项，困难 MRR 0.338→0.354；小调 947 项为 0.359→0.357。扩展或特殊和弦 3,458 项为 0.333→0.344。以输入调式的音阶判定的非调内根音 435 项，MRR 0.301→0.317，NLL 5.098→6.371；低频转移 511 项，NLL 6.662→7.943。此处的根音分类只能描述调外根音，借用和弦及变化属和弦的精确类别仍需验证。Billboard 无可靠大/小调标签。MPB 的作曲家组有升有降，数据无充分依据覆盖 J-Pop、ACG、City Pop、Neo-Soul、爵士和电子等目标风格。

4/4 拍网格测试有 36,757 个样本，保持当前和弦的基线 Top-1 为 76.0%。变阶拍网格模型整体为 68.4%，在网格发生变化时仅 2.3%。按和弦变化建模可避免把占拍保持当成预测续接成功。时值仅用符号 QN，MPB 未用于拍网格。

## 实验 B Factory V8 离线回放

从 Billboard 测试集按组取 100 个输入（83 条源行，17 个窗口）。用前四个事件的已知 QN、拍号、低音及可解析的标注音集构建输入，采用正式 v0.11.0 Worker 的灵感优先列表，取实际返回且满足资格与硬约束的 Factory 候选。G13 生成行单独计数。源内容将根音移调归一化后比较完整尾段，接缝覆盖另以源尾段的实际前一和弦作锚。Worker 输出直接以输入末和弦为锚。以根音和 L1 性质的编辑距离衡量，严格相同为 0，近似为最多 1 次插入、删除或替换，目标至少三个 L1 事件。距离是内容诊断，忽略配音、节奏和音响质量。

| 判据 | 库内可找到 | 带源接缝 | 实际 Worker 可达 | 库中有但 Worker 未达 | 库与回放均缺 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 完全相同 | 27 | 9 | 3 | 24 | 73 |
| 近似（含相同） | 71 | 54 | 9 | 62 | 29 |

Factory 相对排序仅在可达的查询上计分。完整列表 100 个输入共返回 21,021 条 Factory 候选、165 条 G13 行，5 个输入无 Factory 结果。

| 可达样本 | 原序 MRR / Top3 | 纯统计 MRR / Top3 | 前十名混合 MRR / Top3 |
| --- | ---: | ---: | ---: |
| 3 个完全相同 | 0.086 / 0 | 0.187 / 0 | 0.186 / 1 |
| 9 个近似 | 0.180 / 2 | 0.563 / 5 | 0.268 / 3 |

混合只在原 Factory 前十名的受支持位置调整，以两种名次等权求和并用原序打破同分，最高上下文支持低于 10 组时保留该位置。纯统计在一个查询将最佳近似项从第 4 降到 243。原序的 9 个可达近似中有 7 个在 Factory Top3 外，说明这些样本存在排序空间。其余 91 个输入的主限制是素材或可达性；62 个库内有但未达的输入尚无法归因到检索、调性适配、来源接缝或资格的单一步骤。三种排序保持同一候选集合，纯统计和混合均在 Worker 外运行。

## 工程、验收与接续

冻结 Factory V8 / Schema 2 / 1,288 条及 HCA SHA-256 与正式构建清单一致。Release 离线回放的 Worker 中位 / P95 为 329 / 420 ms。Python 全候选评分中位 / P95 为 51 / 97 ms，选定压缩模型 72,997 字节。此测量用于离线代价观察，插件内存、实时预算和实机行为待未来接入时验证。

已通过源输入哈希、作品组及替代候选隔离、概率归一化、未知项回退、移调一致性、序列化读取、同环境重训字节一致和 Factory 候选身份/资格检查。正式核心、工厂数据、G13、分页、用户持久化及安装器无源码差异。本轮构建离线回放工具；实际宿主、听评、插件运行时和安装验收未执行。

方法取舍由主代理决定。语料与授权核对、Factory 回放基础实现由子代理完成；主代理复核划分、模型、独立评估与接入判断。路径和哈希见 [MAP](../MAP.md)，复现及中断恢复见 [RUNBOOK](../RUNBOOK.md#b5-真实音乐续接统计)。下一步优先复用 62 个库内有近似素材但未到达 Worker 列表的输入，定位候选在哪一段退出，同时用独立风格语料复核低频转移和非调内概率退化。
