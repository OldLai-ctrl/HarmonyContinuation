# Phase 5 后续人工验收

本轮不要求立即启动 Cubase。本清单供以后集中验收，真实宿主、音乐试听及正式发布均未完成。以包内 BUILD_INFO.json 的构建提交、开关与 SHA-256 为准。

## 安装与实际状态

默认开发包保持 HarmonyFirst OFF、Phase3A OFF、Abstract OFF。HF实验包和Abstract实验包使用独立编译开关；两者不是同一算法。候选内容包为隔离库，不能覆盖正式Factory V4/657。

换包前关闭宿主，备份完整旧bundle。同一VST3身份在扫描目录只保留一个版本；换包后重新启动宿主。About及本地诊断核实 dev.6、Build ID、HF/P3/Abstract；未分析时显示PENDING，完成分析后的实际状态应与构建配置一致。旧本机ON安装曾被UAC取消，不能当作已安装新版本的证据。

回退时关闭宿主，恢复旧完整bundle或旧Setup，保留独立Factory历史与个人库。Abstract实验可通过换回默认OFF包关闭，不需要Session或数据库迁移。

## 音乐与宿主结果

集中记录扩展音的合理性、原型是否被不合适候选挤掉、Color发展方向、低音连接、重复和弦及实际采用意愿。检查工程保存/重开、键调变化、重复导入、缓存刷新、窗口/DPI与拖放。由“诊断/宿主诊断”保存本地输入和推荐导出，关联实际安装包及场景。

没有合理可续写Color时可以为空；不能把不可循环且已耗尽的路线延长。离线改善不代表R02实机已修复。完成音乐与真实宿主验收后，另行决定内容采纳及正式发布。
