# HarmonyContinuation 0.8.0-dev.1

开发分支 `v0.8/dev` 从 v0.7 的 `4eb34f4aab48344470b808ac9f8483848540d546` 创建。v0.7 与 v0.8 均未完成 Cubase 人工验收；本版仍是开发版。

## 使用方式

两个主模式共用顶部的“旋律约束”和“和声倾向”。默认关闭旋律约束，使用均衡倾向。

点击旋律约束，可选择“和弦内/可用音”或“最高音”，输入 `E4`、`F#4` 等音名，并设置起点和持续时间。只输入 `E` 等音级也有效。时间使用当前导入段落显示的 QN 坐标。首次设置时，继续发展默认指向当前段落之后，升级进行默认指向选中的和弦。

“柔和”保留有冲突的选项但降低评分；“严格”过滤明确冲突。无法可靠判定的色彩音标为待确认，避免误过滤。最高音使用实际声部安排，保留和弦身份；试听、MIDI 导出和快照沿用这一要求。

UI 第一版编辑一个时间化旋律事件。核心与示例文件支持最多 128 个事件。可编辑的多音示例为 `data/benchmark/constraint/multiple_events.json`：E4 在 0–2 QN，F4 在 2–4 QN，G4 在 4–8 QN。现有 `preview_cli` 与 `midi_export_cli` 的场景输入可读取其 `melody` 数组。

稳妥、均衡、大胆与曲风独立。稳妥提高骨架保留要求并收紧编辑预算；大胆提高有依据的色彩和编辑预算。均衡沿用 v0.7 默认配置。

“更多 → 界面缩放”提供 100%、125%、150%。窗口尺寸与缩放独立；系统 DPI 由现有框架处理，用户缩放只作用于界面内容一次。Windows 软件绘制方式继续保留。

## 保存兼容

Session Schema 5 保存旋律事件、和声倾向和缩放。旧的 Schema 1–4 默认恢复为关闭约束、均衡、100%。两类快照新增可选旋律约束字段，旧快照仍可读取；捕获快照时旋律时间与和弦时间一起转换为段落相对位置。

## 自动检查范围

- 16 个约束案例：和弦音、七度、九度、冲突、待确认音、绝对最高音、音级最高音、多事件、严格/柔和、两种推荐动作、试听/MIDI 数据、快照与旧会话。
- 8 个倾向进行：三档 × 两种推荐动作，并检查和声有效性及骨架门槛。
- 缩放布局和 Demo 点击检查覆盖三档缩放 × 三种窗口尺寸。
- 阶段末集中运行完整 CTest、Validator、42 例继续发展、30 例升级进行以及新的小型检查。

## 保留的人工验收清单

Cubase 后续仍需同时确认 v0.7 的临时窗口外部点击/ESC、Intent Completion 和 Voice Leading，以及 v0.8 的旋律约束、三档倾向、缩放、系统 DPI 和工程重开恢复。自动检查不能替代这份宿主验收。

## 当前边界

色彩音分类是简单的第一版规则，不覆盖完整爵士和弦音阶理论。柔和冲突会保留原声部，并在 Why? 中说明；严格条件过多时允许没有推荐。

本版没有 MIDI Import、旋律生成或新的顶层模式，未进入 0.8.0-dev.2。
