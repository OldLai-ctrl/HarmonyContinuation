## 拖出 MIDI（四个入口）

分别从：主界面继续发展、查看更多继续发展、主界面升级进行、查看更多升级进行拖 MIDI 到 Cubase。

- 得到正常 MIDI Part，不弹保存窗口。
- 不自动产生额外 Marker Track、Chord Track 或文字标记。
- 音符、起点、时值、Part 长度正常；继续发展沿用原有范围，升级进行仍为完整变换后进行。
- 任取同一候选点击保存 MIDI 后导入，对照音乐内容相同。保存版仍允许带有说明标记。

## 分组滚动（七组）

继续发展：收束、发展、循环、色彩。升级进行：润色、丰富、进阶。

- 至少选一个有 3 条候选的组；滚轮在组内能看到第三条。
- 每组约两条可见高度；只有 0/1/2 条时保持实际数量，不补候选。
- 滚到后面的候选，直接试听、拖 MIDI、打开 Why / Snapshot，内容对应当前候选。
- 固定一个候选后，列表仍可滚动；“查看更多”保留。
- 组内滚动到顶或底也不带动整页。鼠标移到组之间的空隙，再滚动整页。
- 如方便，在 100% / 125% / 150% 各看一次。
