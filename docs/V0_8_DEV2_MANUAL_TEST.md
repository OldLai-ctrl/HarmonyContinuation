# dev.2 Cubase 人工验收（待测试）

关闭 Cubase 后运行 `build-installer/output/HarmonyContinuation-0.8.0-dev.2-Setup.exe`。打开“更多 → 关于”，确认版本 dev.2，库仍为 2、161 条，个人进行保持。用测试工程。

1. **查看更多**：两种模式各选一条主卡未显示的候选；试听、再次点击停止、换候选替换播放；查看解释，保存 MIDI 和快照。关闭详情时试听继续。
2. **四处拖 MIDI**：继续发展主卡 / 更多详情，升级进行主卡 / 更多详情，各拖到 Cubase MIDI 轨。应生成 MIDI Part、时间长度和音符正常、符合默认 VoiceLed / 完整进行，不弹保存框。拖动取消后插件可继续用；单击仍可保存文件。
3. **导入**：更多 → 导入 MIDI，选择和弦块 `.mid`。核对和弦、转位与节奏、选中轨道 / 调性摘要；继续发展及升级进行能处理该进行。再用“作为未完成进行”，最后一颗应显示 OPEN。可用 `build-v08/midi-import-fixtures/` 的 12 个示例。
4. **Explorer 文件拖入**：将 `.mid` 拖到当前进行时间轴；识别结果应与文件选择一致。这不代表支持 Cubase 私有 MIDI Part 直接拖入。
5. **失败与恢复**：损坏文件 / 单音旋律 / SMPTE 不应覆盖当前进行。保存工程，关闭再打开，导入和弦、时值、OPEN、原约束、语言及缩放恢复；最高音不自动变成旋律约束。
6. **简短界面检查**：100%、125%、150% 看一次新增详情按钮与导入入口；中英文文案正常。

回复：`项目：PASS / ISSUE；现象；截图或文件（失败时）`。实际 Cubase 拖出、试听及工程重开均以用户实测为准。本轮结束后等待结果，不进入下一版本。
