# HarmonyContinuation 0.6.0-rc.2 复测说明

RC2 修复了 RC1 在 Cubase 中显示「试听」「MIDI」「SNAP」但未连接操作的缺陷。继续发展、升级进行和进行库的对应入口现已连接。进行库底部的页码可点击并直接选择目标页。本轮没有修改和声匹配、推荐规则或内置曲库。

## 安装与识别

关闭 Cubase，备份已安装的 RC1，然后安装 `build-rc2/HarmonyContinuation-0.6.0-rc.2-Windows.zip` 中的 `HarmonyContinuation.vst3`。重新打开 Cubase，在插件的「更多 → 关于」确认版本为 `0.6.0-rc.2`。安装版文件可与 `build-rc2/HarmonyContinuation-0.6.0-rc.2-SHA256.txt` 核对。

## 重点复测

1. 在「继续发展」的推荐卡片和对比栏分别点击「试听」；应从 Windows 默认播放设备听到完整已有段落和后续。再次点击同一候选应停止。切换候选或关闭插件窗口时不应留下播放。
2. 在「升级进行」点击「试听」；应听到改造后的整段和弦。
3. 在两种模式及进行库详情中点击「MIDI」；应出现保存对话框。保存后将 `.mid` 导入 Cubase，核对和弦顺序、时长及速度。取消保存应有明确状态提示。
4. 在推荐卡片点击「SNAP」，在升级进行详情点击保存快照；应出现保存对话框并生成对应 JSON 文件。
5. 进入进行库，点击底部页码，从弹出列表选择任意页；列表应立即跳转。原有上一页、下一页继续可用。
6. 「色彩」组的已知非空例：C（4 QN）→ F（4 QN）→ Fm（末尾 OPEN），手动调性 C Major。此例当前可给出 C、G→C、Em7→Am7 等候选。其他输入可能因曲库和评分门槛显示空组；记录具体和弦与时长后再判断是否异常。

试听使用离线生成的音频，经 Windows 默认播放设备播放，当前不走 Cubase 的插件音频总线。若 Cubase 使用与 Windows 不同的音频设备，应检查 Windows 默认设备。MIDI 功能是保存 `.mid` 文件，当前不是拖回 Cubase。
