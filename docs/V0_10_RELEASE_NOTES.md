# HarmonyContinuation v0.10.0

Windows x64 VST3 正式版本，Factory V5 / 658 条。下载与正式资产校验见 [GitHub Release](https://github.com/OldLai-ctrl/HarmonyContinuation/releases/tag/v0.10.0)。源码由 `v0.10.0` Tag 固定；About 的 BuildCommit、VST3 moduleinfo 与正式安装包对应同一提交，精确身份及正式验证结果随 Release 资产提供。

## 本版内容

- 单一 HarmonyContinuation 和弦续写推荐引擎，保留结构/节奏解耦、严格扩展兼容、精确音乐身份及实际用途证据。
- Factory V5：658 条精选进行，继承 V4 的 657 条并新增独立的 15634125 路线；既有历史库保留。
- 收束、发展、循环、色彩与升级进行五类入口。
- 完整合格推荐列表、每页最多 10 条、同序推荐总览与完整清单复制；Top3 为优先标记，探索候选有独立标签。
- 显示真实和弦匹配位置、输入插入及模板跳过；保留来源和推荐理由。
- 普通推荐从库来源起点试听和导出，保留和弦性质、低音、转位与时值；升级进行输出完整升级路线。
- 升级变化采用统一高亮、暖色插入与简洁图例；色彩变化曲线节点位于和弦起点，指数不参与质量评分。
- Host Audio / Windows Audio 双音频试听，支持暂停、恢复、停止与进度定位；整根光标及下端手柄可拖动。
- 配音试听、MIDI 导入、导出及拖放，保留完整/续写范围与候选对象身份。
- 单一离线安装包管理插件和 Factory 两个组件，保留用户曲库、收藏、偏好与旧 Factory 数据。

## 验收与兼容范围

2026-10-23，用户明确确认 RC1 `0.10.0-rc.1 / 435ed852d50346d3c1ae8163451e6580fe4dac9e` 在 Cubase、FL Studio 实机全部验收通过，包含三项 UI 修复。宿主及系统的具体版本组合未在本次报告中提供，不据此扩大兼容声明。

正式版仅变更版本元数据、构建配置及文档，音乐和音频实现与已验收 RC1 相同，因此复用上述用户实机证据。正式二进制另行执行相关 CTest、VST3 Validator、实际模块加载、Factory/Session/Snapshot/用户库检查，以及 RC1→正式版隔离升级和关键安装路径验证。用户实机验收与这些自动化/开发宿主验证分别记录；未宣称正式二进制已重新在两款 DAW 实测。

## 安装与回退

关闭宿主后运行 `HarmonyContinuation-0.10.0-Setup.exe`，默认选择 VST3 和 Factory V5。可直接从 RC1 升级；Session 5、Snapshot 3、用户库及 Factory Schema 2 不变。用户数据仍在本机，不随 GitHub 上传。

RC1、dev.15 及开发分支历史保留。需要回退时先关闭宿主、备份工程与个人库，再通过管理安装卸载正式程序并安装保留的 RC1；不要把两个同身份插件同时放入扫描路径。卸载保留个人库和非本次管理的历史 Factory，详见 [安装与升级](INSTALLER_AND_LIBRARY.md)。

## 已知限制

探索候选的用途证据弱于默认优先推荐。色彩指数表示结构变化，不等于好听程度。没有宣称所有宿主版本、操作系统或音频设备组合均已验证。安装包未数字签名。
