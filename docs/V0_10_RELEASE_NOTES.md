# HarmonyContinuation 0.10.0 — 发布说明草案

**状态：RC1 验收中，正式发布条件待用户确认。** RC1 源码为 `435ed852d50346d3c1ae8163451e6580fe4dac9e`（`435ed85`）。包与验证证据见 [RC 评审](DEV15_RC_REVIEW.md)。用户完成 Cubase 验收并明确确认通过后，进入正式发布流程。

## 本版内容

- 统一为单一 HarmonyContinuation 推荐引擎，保留结构/节奏解耦及严格约束下的扩展和弦兼容。
- 在统一列表中浏览全部合格的默认与探索推荐；探索路线有独立标记，支持分页、完整总览及清单复制。
- 显示推荐和输入之间的实际匹配位置、插入及模板跳过关系，并提供推荐理由与色彩变化信息。
- 普通推荐可从匹配库来源起点试听和导出，保留来源的和弦性质与时值，支持完整/续写范围；升级进行输出完整升级路线。
- 支持 Host Audio 与 Windows Audio 预览，提供播放、暂停、恢复、停止及时间定位。播放光标配有拖动手柄；升级变化使用统一背景语义，色彩曲线节点按和弦起点定位。
- Factory V5：658 条，继承 V4 的 657 条并新增一条独立进行。
- 统一安装包管理插件与 Factory 两个独立组件。保留用户曲库、收藏、偏好及既有 Factory 历史数据。

## 验收状态

- Cubase Pro：RC1 中播放光标手柄、升级进行高亮和色彩曲线节点位置等待用户实机复验；试听、MIDI 与工程恢复按本轮验收清单复查。

- 自动化与开发端验证：引用 RC1 交付报告中的实际结果；本草案不把历史测试或模拟宿主结果表述为本版 DAW 验收。

## 已知限制

推荐质量及用途判断沿用统一引擎。探索路线代表用途证据较弱但仍可访问的候选；它不等同于默认优先推荐。试听为插件生成的预览；实际听感、宿主路由和 DAW 行为以对应版本的真实宿主验收为准。
