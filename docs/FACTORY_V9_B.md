# Factory V9-B 完整后句与发展路线

**结论 B。保留两份实验库和离线功能字段补全。** 新素材增加了合格的完整发展选择；两个确认组的近似实际续接可达均未增加，首页多样性未见稳定收益。下一步应优先研究来源前缀、调中心与完整边界如何共同支持合格后句。

## V9-A 接缝诊断

12 首有目录原生接缝的作品映射到 17 条来源、落点与调性路线。Exact 中 14 条选择了其他落点，3 条在目标落点未达最低匹配；其他落点有 3 条能够通过资格。Contextual 首个决定性退出为内部中心限制 10 条、两事件来源前缀不符 6 条、未尝试对应解释 1 条。17 条里 11 条的末和弦可兼容，仅 2 条也满足静态的双事件前缀。目标路线资格通过 0 条，去重、分页或数量限制造成的丢失为 0 条。B6 所修复的耗尽非循环尾端在原 97 首 V9-A 全轨迹中仅见 1 次。

定位依照三个真实代码路径。ProgressionMatcher 的对齐先选端点，再由 ContinuationEngine 校验最低匹配、末端对齐、资格和硬约束。原 97 首针对 V9-A 增量的 Exact 轨迹中，最低匹配退出 27,473 路、最低资格 86 路。ContextualContinuation 先确认解释与兼容前缀，再检查实际低音、音集接缝、意图与硬约束。原组在内部中心和前缀处分别退出 35,160 路及 23,735 路，实际音集及低音接缝退出 188 路。完整列表映射、去重和分页位于这些阶段之后。来源存在、事件近似或结构证据缺少均不足以证明筛掉了合格音乐。逐项证据见 [外部映射](../MAP.md#v9-b-外部证据身份)。

5 个未通过的原创接缝正控均找到了 Exact 的正确落点，4 个低于最低资格，1 个低于最低匹配。在 Contextual 中，共用前缀的两条被中心限制，另外三条被实际低音或音集接缝拦下。V9-A 编辑序列中有 198 个已存 Unknown 功能事件可由现有分析器在作者调与拍号下推断。三或四次 0.48 功能差代价解释了四事件正控的相似度 0.619 或 0.527；相关角色字段与分析器一致。隔离反事实只补 Unknown 功能，保持音集、低音、QN 和其他投影数据。正控原演奏返回 19/24→24/24；原 97 首作为开发组近似 18→20。两个新命中来自同一条目，均为 Factory 第 318 位，另有 13 条被重投影的旧 V9-A 音乐身份退出。这支持单独试验新增条目的数据缺失补齐，暂不足以支持改运行时、回填冻结旧库或放松 Contextual 接缝。

### 作品隔离及指标

RS200 50 首为 V9-A 未回放作品，排除 A2 早期研究、全部 B5 Billboard/MPB 的标题冲突、V9-A 97 首及可识别相同长窗口。每首固定选取一位作者的一处合格窗口，保留了旧双标注选择可能造成的样本偏差。WJazzD 72 首从 254 首合格作品按固定哈希抽样，以底层作品归并录音，另外排除 RS200 全部标题。两组均为原标注符号 4/4，三小节前段（12 QN）、四小节后段（16 QN），爵士窗口在一个注释 chorus 内。目标为观察窗，曲式的专家后句起点仍可能不同。异名、翻唱和跨来源同曲仍可能残留，风格与拍号范围有限。Jazzomat v2.1 / DB 2.2 按 ODbL 1.0 仅本地评估，不用于训练、素材或产品。原资料及署名见 [RS200 分析](https://rockcorpus.midside.com/harmonic_analyses.html) 与 [Jazzomat 发布](https://jazzomat.hfm-weimar.de/download/download.html)。

同一输入的完整路线统计只计通过现有资格、保留来源尾端且至少三个 L1 事件的输出，以相对前句最后根音的有序根音和性质去重。同根音、同性质的连续占拍合并，扩展音、转位与时值不会制造另一条 L1 路线。另按解释中心做粗功能路径（主、属、下属与其他根音区，保留末音级和性质），仍有结构等价漏判。分别统计同路线的时值向量、原生来源尾端、带设计边界、已有审校结构与未知结构的整句。Top3/10 用 Factory 子序，混排位置同时保存。近似用 B5 完整 L1 尾段编辑距离 ≤1，实际演奏严格比对另加原 QN、音集及已标低音。自动类别是结构代理；本轮没有音乐听评证据。
