## 算子与搜索

`src/generation/PhraseGenerator.*` 是独立模块，生产构建默认关闭 `HC_BUILD_GENERATION_EXPERIMENT`。生成函数只接收实际输入音乐及约束，不查询Factory或来源ID。

| 算子 | 推导与保留的依据 |
| --- | --- |
| 功能连接 | 主/下属/属家族、次属与次导；显式记录预期解决根音，支持欺骗性解决和有上限的悬留延迟 |
| 声部连接 | 共同音、邻近运动、连续上/下行低音、结构音转位、已有或主/属踏音；允许有依据的四/五度重组 |
| 调外探索 | 平行/调式借用、共同音中音关系、三全音替代、带原/目标中心解释的枢纽提案；后文另记目标音集及抵达证据 |

每一步保存种类、机制、实际和弦/低音、共同音、低音音级位移及目标。三个算子可独立调用，也可在同一句中协同。来源为算法构造；目标中心字段表示一种解释，证据不足时不会宣称已经完成转调。

`Relation.kind`标记生成算子通道，实际调外音由音集与语境判断；共同音中音连接也可能留在调内。`outsideChords`相对原中心计数，不能仅凭通道名称给路线加风格或新颖性标签。

默认beam 12、每节点最多16个后继、最多2个语境中心、4/6/8个事件，**整个请求最多16,000次扩展**。意图为自然延续、开放发展、张力/延迟解决、调外色彩、连续低音。调中心分析保留多解，输入以小调开始时保留小调线条的解释机会。搜索保存低音方向/步幅动机、未完成解决目标、已出现的和声核心和目标中心状态；不使用随机轮换或在线生成服务。

后句有明确的4或8小节节奏分组、已知时值、完整结束边界及句尾停顿/悬置。资格先检查时间、实际音集、演奏可实现性、硬约束及意图所需发展；之后比较连接、整句目标、历史相似性和多样性。同音集及同低音的异名不作为新连接；相同上层核心连续使用有界，避免仅改扩展或转位制造整句差异。`structure=1`表示构造检查通过，音乐完整感仍需试听。

## 复用与演奏身份

- 从dev.15复用核心音级连接和整句轮廓证据，保留其排序开关为关闭；正式推荐没有启用该实验排序。dev.15研究记录仍在独立工作树。
- 复用G10–G12的实际音集/低音/时值轮廓及历史相似性。Factory来源的审核资格不授予生成句；生成采用自己的明确构造证据。
- 复用 `HarmonicTendency` 的倾向偏好、现有旋律兼容性及 `ChordVoicer`。硬性音符另要求真正包含于音集，指定顶音须可实际发声；“不确定”解释不能替代这一检查。
- `VoiceLeadingMetrics` 的相邻配音计算抽成共享纯函数，保留原函数数值行为。它测量本次模型配音，不是用户原编曲的声部。
- `HarmonyColorAnalyzer` 提供可用时的色彩张力趋势；不支持可靠分析时保留未知。新旧原始评分不直接混排。
- `GeneratedPhrase` 保存完整E、实际低音MIDI音高、时值、约束、中心解释和每一步关系。ID以 `g13:` 开头。临时Preview适配器没有Factory ID，`baseQualified=false`，不送入正式推荐列表或Snapshot。

原试听器按固定音区安排各低音，单看音级下行会在C处发生八度回跳。G13加入可选的运行时 `Event::bassMidi`，由同一个 `voiceEvent` 供离线试听与MIDI使用，必要时整理上方声部。**没有该值时执行原配音路径**。生成器在C1–C4范围安排实际低音，连续线不靠八度等价来冒充；六条输入D在这一改动前后的模型音频前缀逐字节一致。

G12-2、G12-8的完整D从既有来源MIDI读入，保留末尾已知时值。名称是当前和弦解释，实际音集、低音与时值在JSON中保存；没有宣称唯一恢复原来的和弦命名或编曲。

实际技能：`deja-search`（历史实现/决定检索）、`anti-defensive-writing`（采用适用的简洁工程表达规则，完整保留验证事实）、`stop-that-shit`（限定变更与检查）。主代理负责算子、搜索、音乐结构与来源裁决；LUNA负责CLI及索引的确定性整理。音乐最终判断由用户完成。
