HarmonyContinuation 0.10.0-dev.1 开发候选版 / Development Candidate

Factory Library V4：657 条（629 条继承 + 28 条新增）。
This development candidate includes the matching V4 engine and 657-entry Factory Library V4.
Cubase / FL Studio：本开发构建尚待用户人工验收 / Pending manual DAW acceptance.
安装包未进行数字签名 / The installer is not digitally signed.

主程序和 Factory 曲库是两个独立可选组件，均由此统一安装器管理。
Factory V4 requires plugin 0.10.0-dev.1 or newer. Library-only installation is blocked with an absent, unknown or older plugin.
单独勾选 V4 时，缺少主程序或版本过低会被阻止；同时勾选主程序即可安装匹配版本。
仅更新主程序会保留已有受支持的 Factory 库。此包不适合作为 v0.9.0 的单独曲库更新。

安装、更新、修改组件、修复和卸载均使用同一个 Setup。
未勾选更新不表示删除；删除组件必须选择明确移除操作。
个人库、收藏、设置及不属于当前管理版本的历史 Factory 数据会保留。
不同内容的同版本 Factory 不会被直接覆盖；请保留旧开发库备份再处理版本冲突。
新版插件写入旧个人库时仍沿用 User Schema 2 迁移及一次性备份规则。

升级前关闭 Cubase、FL Studio 及其它占用插件/曲库的程序。安装后重新打开插件实例。
此包使用标准系统 VST3 路径，会更新已安装的插件；v0.9.0 原始安装包和数据备份应保留以便回退。
安装成功并不等于完成宿主验收；请使用随包 V4 人工验收清单。
