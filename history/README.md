# 历史检索入口

仅归档有复用价值的已结束过程：明确根因、尝试结论、证据位置、迁移依据和已被取代的决定。不复制整段聊天、完整日志、安装/发布流水账或当前待办。

按月份存 `history/YYYY-MM/<主题>.md`；持续性主题可用 `history/<主题>/`。文件开头说明事件、来源和适用版本。

先搜索，再读取命中段落：

```powershell
rg -n -i 'DXGI|宿主|交接|具体错误文本' history
rg --files history -g '*handoff*'
```
